# Google Play Reviewer Notes Draft

i-Sight Med does not require login.

To test the core functionality, connect a compatible USB/UVC camera to the Android device using a supported USB adapter. Open the app, grant camera/audio/storage permissions when prompted, and allow USB device access when Android displays the USB permission dialog.

The app previews the connected USB camera and can save photos/videos locally to the device or to a folder selected by the user.

No server account, test credentials, or internet connection are required.
